# 3DYeahTeam

## AssetStoreTools（サブモジュール）

`Assets/AssetStoreTools` は private リポジトリ [3DYeahTeam_AssetStoreTools](https://github.com/HIBIKI5201/3DYeahTeam_AssetStoreTools) をサブモジュールとして参照している（閲覧権限が必要）。クローン時にサブモジュールも取得する。

```bash
git clone --recurse-submodules https://github.com/HIBIKI5201/3DYeahTeam.git
# クローン済みの場合
git submodule update --init
```
